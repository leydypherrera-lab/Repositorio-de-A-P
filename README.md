## 📋 Detalles del Proyecto
**Vibra Musical** es una aplicación web creada en Python con Streamlit, donde se pueden explorar y descubrir canciones en inglés de diferentes géneros. La aplicación permite buscar y filtrar canciones, conocer algunos datos y estadísticas sobre la música, jugar a adivinar géneros musicales y décadas, y guardar las canciones favoritas en una lista personal. La idea es tener un espacio donde los usuarios puedan conocer música nueva y divertirse mientras interactúan con ella.

## 🎯 Reporte de Visión
* **Descripción general:** Plataforma web multipágina compuesta por cuatro módulos (*Inicio*, *Explorar*, *Jugar* y *Mi música / Mis datos*) que integra análisis de datos musicales con mecánicas interactivas y seguimiento de actividad en tiempo real.
* **Objetivos:**
  * Facilitar la consulta y el filtrado dinámico de canciones por género, año de lanzamiento y artista mediante tablas y gráficos interactivos.
  * Ofrecer una experiencia lúdica conectada directamente con los registros reales del catálogo para adivinar el género y la década de cada canción.
  * Permitir al usuario registrar su desempeño en las partidas y organizar o descargar su propia lista de música favorita durante la sesión.
* **Beneficios:** Transforma un conjunto extenso de datos musicales en una experiencia accesible, educativa y entretenida para cualquier usuario sin necesidad de conocimientos técnicos de programación.
